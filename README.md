# Phone & Electronics POS Desktop Application

A desktop-based Point of Sale (POS) system designed for phone and electronics shops. The application helps shop owners manage products, track inventory, process sales and monitor business performance.

## Features

- Product management
- Inventory and stock tracking
- Sales processing
- Customer information
- Receipt generation
- Sales reports
- Desktop application interface

## Technologies Used

- PHP
- SQLite
- HTML
- CSS
- JavaScript
- PHP Desktop
